# Provenance

This folder holds a downstream comparison on a second host model, run on 2026-11-06 and compared only among its three libraries, not with Table 2. The host was `deepseek-v4-flash` (response-side names `deepseek-v4-flash` and `deepseek-v4-flash-0731`) with thinking disabled (`{"thinking": {"type": "disabled"}}`) and temperature 0, running in the activated optskills conda environment with `PIP_NO_INDEX=1` for the host and its code-execution subprocesses. The three libraries (`gate_asdeployed`, `panel_base_3of3`, `vote`) were built once from the stored E1 trajectories with this host, and all 15 library-benchmark evaluations (1,100 items per library) ran serially, one at a time at 12 workers, each with a new run directory and an empty response cache. Earlier attempts were discarded under rules written before they ran: a parallel pass whose protocol failed under load, a pass on `deepseek-v4.1-flash` whose backend was not pinned on the relay and ignored the disabled-thinking setting, and a pass whose environment lacked the conda activation paths so that `numpy.linalg` crashed in the agent's programs. Their records are kept outside the repository.
